# 🎴 OOP Flashcards (`oop-flashcards`)

Ứng dụng học lý thuyết OOP & SOLID được port chuẩn Native sang **Vue 3 + TypeScript + Pinia** từ dự án `AI/FLASHCARD`.

## Tính năng
- 21 câu hỏi phỏng vấn chia theo 7 chủ đề (OOP cơ bản -> SOLID & Design Patterns).
- Thẻ lật 3D, ví dụ code có syntax highlighting an toàn (không dùng `v-html`) và nút sao chép nhanh.
- Hỗ trợ phím tắt (`Space`, `←`, `→`, `↑`, `Enter`) và vuốt trên Mobile.
- Lưu tiến trình câu đã thuộc / cần ôn bằng Pinia Persistedstate (`vibe_oop_flashcards`).
