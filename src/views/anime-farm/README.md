# 🌾 Nông Trại Anime 2.5D (`anime-farm`)

Mini-app được nhúng tĩnh từ dự án **FAM (Farm Anime Mobile)** vào thư mục `public/apps/anime-farm/` và hiển thị qua `AppEmbedFrame`.

## Tính năng
- 12 ô đất Isometric 2.5D mở khóa theo cấp độ.
- Gieo hạt bằng menu tự chuyển ô, kéo thả hoặc gieo nhanh/ngẫu nhiên.
- Tưới nước tăng tốc sinh trưởng, thu hoạch, nhà kho nông sản & đơn hàng thị trấn.
- Lưu tiến trình tự động qua `localStorage` và tổng hợp âm thanh bằng Web Audio API.
